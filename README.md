# Planeswalker's Vault: downloads

**[Download the latest build](https://github.com/PaintBallz/planeswalkers-vault-releases/releases/latest/download/PlaneswalkersVault.exe)** · [All releases](https://github.com/PaintBallz/planeswalkers-vault-releases/releases) · [Website](https://planeswalkers-vault.paintballz.us)

Planeswalker's Vault is a free, fan-made incremental game about opening Magic: The Gathering booster packs on a 3D table, building a collection, and playing Commander pods with the Forge rules engine.

> **Demo, work in progress.** Expect balance changes and bugs, and saves may be reset between versions.

This repository only hosts release builds. The game's source isn't public.

## Running it

1. Download `PlaneswalkersVault.exe`. You need Windows 10 or 11, 64-bit.
2. Windows SmartScreen will say *"Windows protected your PC"* because the demo isn't code-signed. Click **More info**, then **Run anyway**.
3. Stay online the first time you play. Card data and images come from Scryfall.

Each release lists its SHA-256 so you can check the download.
